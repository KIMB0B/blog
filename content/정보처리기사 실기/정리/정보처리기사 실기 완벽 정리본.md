## 📡 1. 통신 및 네트워크 기초

### ✅ 통신 방식 비교

| 방식            | 정의               | 특징            | 예시        |
| ------------- | ---------------- | ------------- | --------- |
| 회선 교환         | 통신 전에 물리적 경로 고정  | 전용선, 실시간, 비효율 | 전화망(PSTN) |
| 패킷 교환 - 데이터그램 | 매 전송 시 경로 결정     | 유연하지만 지연 가능   | 인터넷(IP)   |
| 패킷 교환 - 가상 회선 | 처음만 경로 설정, 이후 고정 | 효율적, 빠름       | ATM, MPLS |

### ✅ 주요 네트워크 프로토콜

| 프로토콜       | 계층   | 설명                              |
| ---------- | ---- | ------------------------------- |
| TCP        | 전송   | 연결 지향, 신뢰성 보장 (3-way handshake) |
| UDP        | 전송   | 비연결, 빠름, 신뢰성 낮음                 |
| IP         | 인터넷  | 주소 지정, 비연결형                     |
| ICMP       | 인터넷  | 오류 메시지 전달 (ping)                |
| ARP / RARP | 네트워크 | IP↔MAC 변환                       |

## ☁️ 6. 클라우드 & 라우팅

### ✅ 클라우드 컴퓨팅

| 구분   | 설명                  |
| ---- | ------------------- |
| IaaS | 인프라 제공 (서버)         |
| PaaS | 플랫폼 제공 (개발 환경 포함)   |
| SaaS | 소프트웨어 제공 (사용만 하면 됨) |

### ✅ 라우팅 프로토콜

| **프로토콜**                               | **분류** | **방식**          | **특징**                     | **사용 용도** |
| -------------------------------------- | ------ | --------------- | -------------------------- | --------- |
| **RIP** (Routing Information Protocol) | 내부망    | Distance Vector | 최대 홉 15개 제한, 단순함           | 소규모 네트워크  |
| **OSPF** (Open Shortest Path First)    | 내부망    | Link State      | 홉 수 제한 없음, 빠름, 대규모 네트워크 적합 | 기업 내부망    |
| **BGP** (Border Gateway Protocol)      | 외부망    | Path Vector     | 자율 시스템(AS) 간 라우팅, 인터넷 전용   | 인터넷 백본    |

#### **🔎핵심 용어 정리**

| 용어                  | 의미                  |
| ------------------- | ------------------- |
| **Distance Vector** | 거리(홉 수) 기반, 단순함     |
| **Link State**      | 링크 상태 기반, 정확하고 빠름   |
| **Path Vector**     | 경로 정보 + 정책 기반 (BGP) |

## 🧾 8. 오류 제어

| **구분**      | **기법**                  | **기능**         | **특징**         | **암기 포인트**   |
| ----------- | ----------------------- | -------------- | -------------- | ------------ |
| ✅ **오류 검출** | **패리티 비트 (Parity Bit)** | 1비트 오류 감지      | 짝수/홀수 개수 체크    | “오류 있는지 확인만” |
|             | **CRC (순환 중복 검사)**      | 오류 검출          | 다항식 계산 기반      | “수학으로 오류 감지” |
|             | **해밍 코드(Hamming Code)** | 1비트 오류 검출 + 정정 | 패리티 비트 여러 개 사용 | “정정까지 가능”    |
| ✅ **오류 정정** | **FEC (전방 오류 정정)**      | 수신자가 자체 정정     | 재전송 없음         | “알아서 고친다”    |
|             | **BEC (후방 오류 정정)**      | 수신자가 재전송 요청    | 피드백 필요         | “틀리면 다시 보내!” |
