# 3번

### **📌 응집도(Cohesion)란?**

- 하나의 모듈(함수, 클래스 등)이 **얼마나 하나의 책임(기능)**에 집중하고 있는지를 나타내는 지표입니다.
- **높을수록 좋고**, **낮을수록 유지보수가 어렵고 오류 가능성도 큽니다.**

### **📊 응집도의 종류 (높은 순 → 낮은 순)**

| **응집도 수준**                   | **설명**                          |
| ---------------------------- | ------------------------------- |
| **우연적 응집 (Coincidental)**    | 관련 없는 기능들이 모여 있음 (최악)           |
| **시간적 응집 (Temporal)**        | 시간적으로 비슷한 시점에 수행됨               |
| **논리적 응집 (Logical)**         | 비슷한 범주의 기능이 모여 있음 (예: 입출력 처리 등) |
| **절차적 응집 (Procedural)**      | 일정 순서대로 수행되는 기능이 모여 있음          |
| **통신적 응집 (Communicational)** | 동일한 데이터를 사용                     |
| **순차적 응집 (Sequential)**      | 앞 결과가 다음 기능의 입력이 됨              |
| **기능적 응집 (Functional)**      | 단 하나의 기능을 수행 (최상)               |

# 6번

### **📊 정규형 되었는지 확인**

| **정규형** | **키워드**  | **확인법 요약**                                |
| ------- | -------- | ----------------------------------------- |
| 1NF     | 반복 속성 제거 | 한 셀에 여러 값 있는지 확인                          |
| 2NF     | 부분 종속 제거 | 기본키가 2개 이상일 때 일부 키로 결정되는 속성 유무 확인         |
| 3NF     | 이행 종속 제거 | 해당 테이블과 관련없는 값의 ID와 값이 다른 테이블로 분리되어있는지 확인 |

# 8번

## **✅ 정보처리기사 실기용 조인 정리표**

| **조인 종류**                | **설명**                       | **키워드**           | **예시/특징**     |
| ------------------------ | ---------------------------- | ----------------- | ------------- |
| **세타 조인 (Theta Join)**   | 조인 조건이 = 이외도 가능한 조인          | >, <, >=, <=      | 다양한 조건 가능     |
| **동등 조인 (Equi Join)**    | 조인 조건이 = 인 조인                | 등호                | 중복 속성 남음      |
| **자연 조인 (Natural Join)** | 같은 속성 이름을 기준으로 자동 조인 + 중복 제거 | 자동 중복 제거          | 속성 이름 같아야 함   |
| **내부 조인 (Inner Join)**   | 조건을 만족하는 튜플만 반환              | JOIN ... ON       | 가장 기본 조인      |
| **외부 조인 (Outer Join)**   | 조건을 만족하지 않는 튜플도 포함           | LEFT, RIGHT, FULL | NULL 포함 가능    |
| **셀프 조인 (Self Join)**    | 자기 자신과 조인                    | 별칭 필요             | 계층구조 비교에 사용   |
| **크로스 조인 (Cross Join)**  | 모든 조합 반환 (카티션 곱)             | 곱집합               | 조건 없으면 전부 곱해짐 |
